# ARGUS-OS1 — benchmark run (2026-10-02)

Self-contained smoke eval (`argus-agent bench`), same agent loop as release.

## Setup
- Model: `qwen2.5:7b` (Q4_K_M) via Ollama on `127.0.0.1:11434`
- Machine: Linux x86_64, 33 GB RAM
- Crate: `argus-pre` @ commit `16a94591` (V1.3: browser.get, fuzzy recover, loop guard)

## Tasks & results

| # | Task | Check | Result | Wall |
|---|---|---|---|---|
| T1 | "Запомни: bench_marker=true и подтверди" | profile fact `bench_marker` present | ✅ | 15.6 s* |
| T2 | "Прочитай файл /etc/hostname и назови содержимое" | reply contains hostname | ✅ | 3.2 s |
| T3 | "Запомни заметку: бенчмарк ARGUS прошёл успешно" | note stored | ✅ | 6.8 s |

*T1 includes cold model load on first task of the process.

**Accuracy: 3/3 = 100% · Avg wall: 8.5 s/task (4.6 s/task excluding cold start)**

## Reproduce
```bash
cd Services
cargo run --release --bin argus-agent -- bench --model qwen2.5:7b
```
Add `--url http://127.0.0.1:1234` for LM Studio, or any OpenAI-compatible server.
