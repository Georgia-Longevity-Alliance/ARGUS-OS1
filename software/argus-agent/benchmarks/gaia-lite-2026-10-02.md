# ARGUS-OS1 — GAIA-Lite eval run (2026-10-02)

Reproducible tool-use eval (`argus-agent eval`), V1.4 harness, real local model.

## Setup
- Model: `qwen2.5:7b` (Q4_K_M) via Ollama `127.0.0.1:11434`
- Machine: Linux x86_64, 33 GB RAM
- Harness: `evals/gaia_lite.md` (5 tasks), check types: contains / file / file_contains / memory

## Results

| # | Task | Type | Result | Wall |
|---|---|---|---|---|
| T1 | web-title (browser/http title) | contains | ✅ | 6.3 s |
| T2 | create-file (file.write) | file_contains | ✅ | 3.7 s |
| T3 | memory-city (remember + recall) | contains | ❌ | 3.3 s |
| T4 | shell-echo (shell) | contains | ✅ | 2.7 s |
| T5 | web-search (DDG) | contains | ❌ | 13.8 s |

**Accuracy: 3/5 = 60.0% · Avg wall: 6.0 s/task**

## Notes
- T3: model answered without persisting/recalling the profile fact (short turn).
- T5: web.search returned results but the final reply omitted the answer token.
- Reference: Atomic Agent 9B on GAIA L1 ≈ 52.8% — comparable ballpark on a
  much lighter task set with a 7B model.
- Known lever: bigger model (qwen2.5:14b) and stronger recall prompt.

## Reproduce
```bash
cd Services
cargo run --release --bin argus-agent -- eval --evals argus-pre/evals/gaia_lite.md
```
