# CLEANING_OPTICS — чистка оптики по ходу света (камера в окуляре)

> Дата: 2026-11-06
> Схема: камера ToupCam UCMOS00350KPA вставлена **в окуляр** микроскопа (не в фото-порт).
> Статус на день записи: положение зеркала исправлено, свет доходит до камеры — нужна чистка по всему ходу.

## Оптический ход (по нему чистим)

```
источник → конденсор → образец → объектив → тубус → окуляр → стекло камеры (сенсор)
```

Приоритет поверхностей (по важности для чистоты кадра):
1. **Стекло камеры** — нижняя часть корпуса, что вставлена в окуляр (ближайшее к изображению).
2. **Окуляры** — обе линзы: верхняя (контакт с корпусом камеры) и нижняя (к тубусу).
3. **Объектив** — передняя линза.
4. **Конденсор / коллектор у источника** — снаружи.
5. **Препарат / покровное стекло** — самая частая «грязь» в кадре.

## Чем чистить

| Чем | Для чего |
|---|---|
| **Груша / air blower** | Сдуть пыль со ВСЕГО — первый шаг всегда |
| **Оптические салфетки** — PEC-PAD / lens tissue / lint-free | Основная чистка |
| **Изопропиловый спирт ≥90%** (или метанол/этанол) | Жир, отпечатки, масло |
| **Дистиллированная вода** | Убрать разводы после спирта |
| **Ватные палочки, обёрнутые в lens tissue** | Узкие места (объективы) |

**НЕЛЬЗЯ:** бумажные полотенца, голая вата, ацетон, аммиак, сухая протирка по пыли, спирт на дешёвой салфетке.

## Как (процедура)

1. **Сначала сдуть всё грушей** — никогда не тереть по пыли (песчинка = царапина).
2. **Стекло камеры:** груша; жир — капля спирта на салфетку, один проход, без нажима.
3. **Окуляры (обе линзы):** сдуть → спирт+салфетка, круговое движение от центра к краю, сухой салфеткой убрать разводы.
4. **Объектив:** та же процедура; если было иммерсионное масло — спирт дочиста.
5. **Конденсор/коллектор:** сдуть; стёкла снаружи — спирт+салфетка.
6. **После каждого шага — проверка по камере.** Не чистить лишнего: каждая протирка — риск.
7. **Прогон до/после:** снимок камерой (Space) → сравнить чистоту.

## Зеркало (положение исправлено)

**Только груша. Не тереть.** Покрытие зеркала сверху (first-surface) — царапается мгновенно.
Протирка допустима лишь если пятно не сдувается: капля спирта, один проход, без давления.

## Тест «где пыль» (для схемы «камера в окуляре»)

| Движение пыли | Где она |
|---|---|
| Поворот камеры | На стекле камеры |
| Поворот окуляра | На линзе окуляра |
| В фокусе, движется со столиком | На препарате |
| В фокусе, неподвижна | Объектив / внутренняя оптика тубуса |

## Ориентир чистоты

Изображение чистое, **без ореолов и разводов**. Разводы от спирта убираются вторым проходом сухой чистой салфеткой.
